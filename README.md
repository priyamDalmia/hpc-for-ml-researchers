# hpc-for-ml-researchers
Practical guide and reproducible scripts for running large-scale ML, RL, and LLM experiments on PBS Pro HPC clusters.

Worked examples target the [UTS eResearch HPCC](https://hpc.research.uts.edu.au) but generalise to most academic HPC.
 

## Who this is for

ML/RL/LLM researchers — typically PhD students — who:

- have access to a university HPC cluster and want to use it well.
- come from a software/data-science background rather than a traditional HPC one.
- want their experiments to be reproducible by default. 

## What's here

This repo is a work in progress and will grow with new problems and write up the solutions. Current contents:

- `docs/` — organised by topic
- `templates/` — PBS job script templates
- `scripts/` — utility scripts (resource auditing, environment setup, etc.)
- `examples/` — end-to-end worked examples

See [`/00-start-here.md`](guide/00-start-here.md) for a recommended reading order.
